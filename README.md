## 2. Hướng dẫn thêm 6 ảnh mặt đèn
Giải nén 6 file ảnh PNG đã xử lý (`den-bai17.png` đến `den-bai22.png`) vào thư mục `img/`.

## 3. Hướng dẫn chạy & Deploy Netlify
1. Mở trực tiếp `index.html` bằng trình duyệt Chrome hoặc Edge để kiểm tra trên máy.
2. Đẩy toàn bộ thư mục `bai-tap-24/` lên repository GitHub.
3. Kết nối repository vào Netlify (`Build command`: để trống, `Publish directory`: `.`) để nhận link trực tuyến.
